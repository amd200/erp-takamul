Design 4 assets
===============

terms.png is the unchanged terms image from the invoice supplied for this template.

Wafeq Regular, SemiBold and Bold are bundled locally so invoice printing does not depend
on an external font server. Original font files come from Wafeq's official CDN:
https://cdn-public.wafeq.com/cms/static/fonts/Wafeq-Regular.woff2
https://cdn-public.wafeq.com/cms/static/fonts/Wafeq-SemiBold.woff2
https://cdn-public.wafeq.com/cms/static/fonts/Wafeq-Bold.woff2

Reference weight mapping: 400 for invoice data, item amounts and remarks;
600 for company/document titles, field labels, table headings and Notes;
700 for product names and summary totals. Each weight uses its own font file.


The company logo and invoice QR code come from the current invoice data.
